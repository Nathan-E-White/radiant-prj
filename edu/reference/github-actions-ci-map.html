Radiant CI: quick reference

The three rules to recall before editing a workflow.

1. PR commits can run twice

pull_request: runs for the PR; unfiltered push: also runs for every branch push. Restrict push validation to main (and any release branches).

2. Required workflows must not be path-skipped

A required workflow skipped by event-level paths filtering leaves its status pending. Keep the workflow running and conditionally skip only heavyweight jobs.

3. A required gate should always conclude

Keep a final job called verify, give it if: always(), and make it fail when a job that was required for the changed paths failed.
